# 复试资料小程序同步指引

本指引汇总了将本项目复试资料迁移到微信小程序端所需的软件、操作步骤与发布前检查清单，方便教研与运营同学快速复用现有数据结构。

## 必备软件
- **微信开发者工具（WeChat DevTools）**：用于创建 / 预览 / 上传小程序项目，建议使用官方 1.06 及以上版本并使用同一微信号登录。
- **Visual Studio Code 或 WebStorm**：编辑小程序源代码，便于同步本项目中的 TypeScript / JSON 数据结构。
- **Node.js 与 npm**：保持与本仓库一致的依赖版本，以便在小程序端复用 JSON 数据或通过云函数调用后端接口。

## 操作步骤
1. 注册微信小程序账号并在微信公众平台获取 AppID，服务类目建议选择“教育培训”或符合业务的分类。
2. 在微信开发者工具中新建项目，类型选择 **小程序**，将本仓库克隆到本地后指定 `miniprogram` 目录为项目根目录。
3. 按需拷贝 `frontend/src/components/UniversityAdvisorPanel.tsx` 与 `server/src/utils/universityAdvisor.js` 中的院校推荐/复试资料数据，整理为 JSON 文件存放到 `miniprogram/data/` 目录，供页面直接引用。
4. 为自我介绍、专业课资料、英语复盘等模块分别创建页面（例如 `pages/intro/index`），通过 tabBar 或导航按钮切换。在 WXML 中可以结合 `scroll-view` 与 `rich-text` 展示长列表内容。
5. 如需与现有推荐服务打通，可在 `miniprogram/cloudfunctions/` 下创建云函数，转发到服务器的 `recommendUniversities` 接口，实现分数段智能推荐。
6. 编译样式后使用“编译-预览”在真机测试，重点检查长列表滚动与富文本排版在小屏幕上的展示效果。

## 发布前检查
- 在微信开发者工具内执行 `npm install` 与 `npm run lint`（如使用框架）确保无语法错误。
- 若需要嵌入 H5 页面，请在微信公众平台配置 web-view 业务域名；如使用云函数，请绑定云开发环境。
- 填写版本信息、上传代码，并在“提交审核”时附上各功能页面的操作录屏与说明，等待审核通过后即可发布。

## 提示
若希望快速上线，可临时在小程序中使用 `web-view` 组件嵌入本系统的 H5 页面，后续再逐步替换为原生组件，兼顾时效与体验。

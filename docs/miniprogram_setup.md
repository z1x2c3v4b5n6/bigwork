# 研招复试冲刺工具箱 · 微信小程序端

本目录提供与 Web 端同源的数据与排版，可直接导入微信开发者工具进行预览、真机调试与上传。

## 目录结构

```
miniprogram/
├── app.js / app.json / app.wxss      # 小程序入口与全局样式
├── project.config.json               # 微信开发者工具配置，可直接导入
├── data/                             # 复试资料数据源（分数段策略、院校推荐等）
└── pages/
    ├── index/                        # 工具箱主页，入口导航
    ├── intro/                        # 复试自我介绍模板（含中英文）
    ├── subjects/                     # 专业课高频题整理表 + 院校推荐
    └── english/                      # 英语口语快速复盘清单
```

## 使用步骤

1. 安装并打开 **微信开发者工具**（桌面端），使用任意小程序账号登录；若暂无正式 AppID，可保留 `touristappid` 进行开发测试。
2. 在“项目”面板选择 **导入项目** → 选择本仓库中的 `miniprogram` 目录 → AppID 可填 `touristappid` 或自己的测试号 → 点击“导入”。
3. 工具会自动编译并加载四个页面，可在左侧页面树查看：
   - `pages/index/index`：资料入口导航；
   - `pages/intro/index`：分数段策略 + 双语模板；
   - `pages/subjects/index`：支持下拉筛选专业、查看 20 个热门专业院校推荐；
   - `pages/english/index`：7 天复盘计划 + 紧急应对模板。
4. 如需真机联调，在微信开发者工具中点击“预览”，使用手机微信扫码即可进入体验版。
5. 若要上传版本，使用拥有发布权限的小程序 AppID，点击右上角“上传”并按提示填写版本号与备注即可。

## 常见问题

- **如何更新数据？** 在 `miniprogram/data/resources.js` 中编辑对应数组即可，保存后微信开发者工具会自动热更新。若需要与 Web 端保持一致，可在两侧同步修改。
- **如何适配自有品牌色？** 可在 `miniprogram/app.wxss` 中调整主题色、阴影及卡片圆角，修改后重新编译即可。
- **如何扩展更多页面？** 参考现有 `pages/*` 目录结构，新建页面后在 `app.json` 的 `pages` 数组中追加路径即可被微信开发者工具识别。

完成上述步骤后，即可在本地体验微信小程序版的复试工具箱，并根据机构需求进行二次迭代。
